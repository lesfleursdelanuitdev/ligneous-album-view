# @ligneous/album-view

Shared TypeScript types and helpers for **virtual / generated GEDCOM album** views (cover selection, media kind, individual display names, etc.).

Used by the Gonsalves genealogy admin and public site. Published only as source on GitHub; consumers typically depend via `file:` from the monorepo or copy the package.
